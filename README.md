# Developer Portfolio

**Live Deployment:** [View Portfolio Here](https://is-project-2026.github.io/personal-porfolio-169684)

## About The System
This is a responsive, single-page developer portfolio built to showcase my software engineering projects, technical skills, and professional experience. 

This project was developed as part of the IS-PROJECT-2026 Mini-Project Git Workflow Challenge, demonstrating Agile project management, CI/CD deployment, and professional Git practices.

## Technologies Used
* **Frontend:** HTML5, CSS3 (Flexbox/Grid, CSS Variables), Vanilla JavaScript
* **Core Stack Featured:** React, Node.js, Kotlin, Jetpack Compose
* **Deployment:** GitHub Pages
* **Version Control:** Git & GitHub (Conventional Commits, Feature Branching)

## Local Development
To run this project locally:
1. Clone the repository.
2. Open `index.html` in any modern web browser. No build steps are required.
