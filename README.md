## About The System
This is a responsive, single-page developer portfolio built to showcase my software engineering projects, technical skills, and professional experience. 

This project was developed as part of the IS-PROJECT-2026 Mini-Project Git Workflow Challenge, demonstrating Agile project management, CI/CD deployment, and professional Git practices.

## Technologies Used
* **Frontend:** Vue.js, Tailwind CSS
* **Core Stack Featured:** React, Node.js, Kotlin, Jetpack Compose, Python, OpenGL
* **Deployment:** GitHub Pages (Static site generation)
* **Version Control:** Git & GitHub (Conventional Commits, Feature Branching)

## Local Development
To run this project locally, ensure you have Node.js installed:
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the local development server.
4. Run `npm run build` to compile the static assets for production deployment.
